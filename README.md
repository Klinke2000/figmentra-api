#Figmentra-api

Figmentra is a backend project for managing tabletop miniature collections and organizing army lists, factions, and battles.

Built with C# and ASP.NET Core, the project provides a RESTful API for managing game-related data and tracking battle statistics. It is designed with maintainability, clean architecture, and automated testing in mind.

The project is developed as a hands-on learning experience in modern .NET backend development, including API design, database integration, dependency injection, and testing.
