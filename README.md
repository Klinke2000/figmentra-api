# Figmentra API

Figmentra is a backend project for managing tabletop miniature collections and organizing army lists, factions, and battles.

Built with **C#** and **ASP.NET Core**, the project provides a RESTful API for managing game-related data and tracking battle statistics. It is designed with a focus on maintainability, clean architecture, and automated testing.

This project serves as a hands-on exploration of modern .NET backend development, covering API design, database integration, dependency injection, and testing.
